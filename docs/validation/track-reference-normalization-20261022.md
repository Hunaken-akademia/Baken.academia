# 公式馬場参考資料の整理結果

## 対象と出典

公式資料収集の成果物12391020850（実行39694750109）・12391031902（実行39695431573）を読取専用で再処理した。原文SHA256を照合し、HTTP 200の404ページ1件を除外、URLで重複排除した結果339資料（HTML242・PDF36・画像61）となった。重複URLで原文ハッシュが異なる場合も別の取得版として索引に記録する。原資料そのものはそれぞれの収集成果物に保持される。

339は日別観測の件数ではなく、ニュース一覧・告知・添付図等も含む。`normalize_track_references.py` は明確に対応した書式のみ数値化し、それ以外は出典索引と確認待ちに残す。

## 確認待ち

- PDF36・画像61は計97資料。図の配置、丸で囲まれた天候・馬場状態、内柵からの距離と数値の対応を確認する必要がある。数字列の読み順だけで測定値にしない。
- HTML169資料は対応する数値書式がない、一覧・説明・工事資料等。処理済みであることと、測定データが取れたことを区別する。
- 水沢2025年12月20日の公式告知には砂厚が「11cm～10cm」と記載されていた。上下を自動で入れ替えず、読取エラー1資料として別記した。
- 大井・金沢の503応答とホスト停止は取得不可一覧に残した。資料がないことを数値0として扱わない。
- 笠松は106か月の一覧を取得したが、実際に見つかった過去測定表は限定的だった。2018～2026年の測定系列が揃ったとは扱わない。

## 保存・検証

出力は `references.json`（構造化情報）、`source-index.json`（全資料の索引）、`unavailable.json`（取得不可等）、`source-versions.json`（別取得版）、`report.json`（件数と限界）。原資料の再取得やSupabase更新、本番モデル・画面の変更は行わない。GitHub Actionsの単発整理ジョブで90日保存する。

対応書式・実測と目標/見込みの区別・欠測年・旧値と新値・逆転範囲の非修正・公開日の扱い、および既存コレクタのテストを確認する。
