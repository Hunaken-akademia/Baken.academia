# 地方競馬の砂厚・馬場研究

砂厚（cm）と芝のクッション値は別指標です。本研究は地方の実際の公開項目を取得し、既存のレース結果と照合します。予想モデル・順位・買い目は変更しません。

## 取得範囲

- 高知：公式の馬場状態カテゴリ（36）を公開REST経由で2019年以降取得。4区間の内から1mごとの砂厚、測定時刻、記事の公開・更新時刻、URL、原文ハッシュを保存します。全4区間を数値として取得できない告知は除外理由を残します。
- 名古屋：公式砂情報の整備履歴を日付・作業・区間ごとのイベントとして保存。砂厚の数値を推定しません。
- 門別：2026年4月の砂厚調整告知を原文・出典付きで保存。全開催日の実測へ展開しません。
- 盛岡：2025年第6回前半の走路状況を原文・出典付きで保存。含水率3～5%は散水管理の目標であり、日別実測として使いません。

公式出典：
- https://www.keiba.or.jp/?cat=36
- https://www.nagoyakeiba.com/info/race/dirt_course/index.html
- https://www.hokkaidokeiba.net/topics/main.php?p_tcd=0000007623
- https://www.iwatekeiba.or.jp/news/condition-250806

## 解析

保存済みの2024～2026年地方競馬データを読取専用で取得します。高知の砂厚は同日一致だけで結合し、欠測日の補完はしません。内側1m地点の4区間平均と3m以遠の全測定値平均の差を、事前固定の3区分（1cm以下、1～2cm、2cm超）に分けます。実際の走行位置とは異なります。

脚質は馬ごとの前日以前の通過順が得られた最大5走（最低2走）の最初の通過順位／頭数から、前方・中団・後方に分類します。今回のレースや同日の通過順を入力に使いません。通過順がない馬を着順・人気から代用分類しません。2025年と2026年を分け、馬場状態別の出走数・対象日数・勝率・3着内率を記述集計します。

現時点の公式記事を再取得しているため、過去の発走前公開や記事改訂履歴を保証できません。レース時刻との照合も未実施です。記述的な関連の調査であり、発走前バックテスト・因果効果・予測改善・回収率ではありません。クラス・距離・人気・季節による交絡も残ります。脚質の履歴が不足する場合は、解析不能の母数を明記します。

## 実行と保存

`python scripts/nar_track_research.py --output artifacts/nar-track --since 2019-01-01`

`python scripts/nar_track_research.py --input-dir .nar-dataset --measurements artifacts/nar-track/kochi-measurements.json --output artifacts/nar-track`

GitHub Actionsの既存NAR研究ワークフローに `[nar-track-research]` 専用ジョブを追加。既存のモデル公開処理は実行しません。取得原文・出典・集計JSON・照合データ・レポートを90日間の研究成果物として保存します。取得失敗を空の成功報告へ置き換えません。

検証：実際の公式書式、旧形式、管理目標の除外、当日・未来情報の遮断、欠測日の非補完を6件のテストで確認。
