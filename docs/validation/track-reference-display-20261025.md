## 保存とアクセス

`rein_track_references` に保存。原本・測定データ・SQL投入ファイルはGitへコミットしない。
`scripts/prepare_track_reference_display.py` が既存の収集結果から再実行可能な投入SQLを生成する（250資料ずつ、upsert）。

APIは既存の会員認証・中央／地方プラン判定・レート制限がかかる `/api/races/track-reference` と `/api/nar/track-reference` 配下。テーブルはRLS有効、対応リーグの有効会員のみSELECT可、anon読取不可、会員の書込権限なし。

`supabase/tests/track_references_rls.sql` により有効オール会員の両リーグ読取、非会員の読取拒否、anon読取拒否、会員書込拒否を実DBで確認。既存の会員レコードは変更していない。新テーブルに関するセキュリティアドバイザー指摘なし。
