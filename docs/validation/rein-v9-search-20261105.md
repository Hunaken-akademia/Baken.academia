# REIN v9 探索：3万通りの設定を段階的な検証で絞り込む（2026-11-05 準備）

研究専用です。本番のモデル・買い目・画面は変更しません。

## 探索する設定

1つの設定は次の組み合わせです。乱数で3万通り（重複なし）を作り、現行（人気70%＋v4 30%、温度1、展開なし、9頭）を必ず含めます。

| 要素 | 候補 |
| --- | --- |
| 着順モデル | v4（本番の特徴量）／v7（v4＋REIN指数） |
| 市場との組み合わせ | 線形配分（人気50〜100%、5%刻み、人気確率は 1/人気^α、α=0.6〜2.0）／学習した市場合成（交互作用あり・なし × 正則化3段階） |
| 着順ごとの温度 | 1・2・3着それぞれ 0.8〜1.25（確率の尖り方の補正） |
| 展開シナリオの効かせ方 | 0（なし）〜1.5 |
| 当日傾向 | なし／常時／判定つき（必要レース数2〜4 × 判定の厳しさ z=1.5〜2.5） |
| 組み合わせに使う頭数 | 9／11 |

## 偶然の当たりを避ける手順

1. 着順モデル・展開モデルは拡大窓で学習し、採点する年より前のデータだけを使う。市場合成は2022年だけで学習する。
2. 段階A：2023〜2024年から固定の1,500レースを抜き出し、3万通りすべてを採点する。
3. 段階B：券種ごと（と複数馬6券種の平均）に上位120を、2023〜2024年の全レースで採点し直す。
4. 段階C：各対象の上位10設定を2025年で比べて1つ選ぶ。2026年は選択に一切使わない。
5. 選んだ設定の2025年・2026年の現行との差に日単位ブートストラップ95%区間を付け、両方の下限が0を超えたら pass。上位10設定すべての2026年の結果も載せ、選択による運の影響が見えるようにする。

買い目の的中判定は `src/baken_academia/ticket_search.py` でまとめて計算します。上限点数の中で確率順に選ぶ従来の買い目生成と、結果が完全に一致することをテストで確認しています。

## 独自性の分析

スクリーニング結果から、要素ごと（REIN指数の有無、市場合成か配分か、展開シナリオ、当日傾向、頭数など）に現行比の平均上積みを集計します。REINの独自要素のうち、どれが実際に精度へ効いているかを示します。

## 実行

`main` へのコミットメッセージに `[rein-v9-search]` を含め、`.github/rein-v9-search-request.json` を更新すると `rein-v9-search` ジョブだけが動く（最長5時間40分）。結果は成果物 `rein-v9-search-<run id>` の `report.json`・`summary.md`・`screen.csv.gz`（全設定の採点）。

## 1回目の実行（run 42098104065）の訂正

1回目はワイドと枠連の的中判定に誤りがあり、出走頭数が組み合わせに使う頭数（9／11）より多いレースで的中を取りこぼしていました。

- ワイド：3着以内の3頭すべてが対象馬に入っていないと不的中にしていた（正しくは当たりの2頭だけ入っていればよい）。
- 枠連：1・2着馬そのものが対象馬にいないと不的中にしていた（正しくは同じ枠の別の馬で枠の組がそろえばよい）。

このため現行の2026年ワイドが76.17%（v7・v8の正しい値は91.06%）、枠連が77.58%（同81.80%）と低く出て、9頭→11頭の効果と両券種・6券種平均の上積みが過大になっていました。単勝・複勝・馬連・馬単・3連複・3連単は判定に影響なし。修正後、頭数を絞るレースでも従来の買い目表と一致することをテストで確認し、再実行しています。
