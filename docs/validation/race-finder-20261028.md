# 条件でレースを探す（固め・中穴・荒れそう）: 2026-10-28

## 指標

単勝オッズを正規化した暗黙の勝率 p_i から、人気の割れ具合 = exp(−Σ p_i ln p_i)（何頭分に人気が分かれているか）を計算します。1頭に集中すると1、全頭同じオッズなら出走頭数になります。5頭未満、またはオッズ欠測・1倍未満を含むレースは分類しません。

## データ

`rein_race_snapshots` の live スロットのうち、予想の出どころが発走前保存（prediction.source = "prestart"、generatedAt < starts_at）で、3連単の払戻があるレースだけを使いました。オッズは発走の約4〜5分前（中央値。90%点で約10分前）のものです。後から再構築した予想（rebuilt）は、オッズが確定寄りで分布がずれるため使っていません（地方の3分位点が rebuilt 4.47／5.80、発走前 4.99／6.57）。

前半（地方 2026-09-28〜10-13、中央 09-27〜10-12）の3分位点で区切りを決め、後半で確認しました。区切りは払戻を見て最適化していません。

## 画面の○✕

固め＝3連単が万馬券にならず、中穴＝3連単30倍以上、荒れそう＝3連単万馬券で○。発走前に保存したオッズで分類したレースだけを判定し、再構築分は「参考外」と表示します。表示中のレースは閲覧時点の最新オッズで分類するため、朝や前日のオッズでは区分が変わることがあります。的中や利益を保証するものではありません。

## 実装

`rein-web/lib/race-finder.ts`（指標・区切り・参考値）、`lib/race-finder-server.ts`（当日の live スナップショットを読み、行を版ごとにキャッシュ。出典サイトへの追加アクセスなし）、`components/race-finder.tsx`。JSの計算値は検証SQLと一致（新潟1R 2026-10-25: 8.3815700491）。2026-10-27の実データでの振り返り（地方59R）：荒れそう○13✕6、固め○16✕6、中穴○13✕3。
