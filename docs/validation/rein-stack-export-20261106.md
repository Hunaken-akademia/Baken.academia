# 市場合成の固定（影運用の準備、2026-11-06）

研究専用です。本番のモデル・買い目・画面は変更しません。

v7・v9で両年の採用基準を通った「学習した市場合成」を、影運用で使う形に固定します。

- 入力：人気（1/人気を正規化）と、本番と同じ設定の着順モデル（v4、2024年までで学習）の1・2・3着確率。
- 合成：着順ごとの条件付きロジット。特徴量は人気と着順確率の対数（と人気の対数の2乗）だけで、レース条件は使わない（v9で効果がなかったため）。正則化は l2=1。
- 確認：2025年で学習し、2026年（〜9月）をWeb版と同じ点数（単勝3・複勝3・枠連11・馬連17・ワイド14・馬単28・3連複34、枠連のゾロ目なし、9頭）で現行70/30と比べる。
- 書き出し：2025〜2026年で学習し直した係数を `REIN_STACK_JSON` としてログに出し、`rein-web/lib/market-stack-v1.json` に固定する。影運用ではこの係数を変えない。

実行：`main` へのコミットメッセージに `[rein-stack-export]` を含め、`.github/rein-stack-export-request.json` を更新すると `rein-stack-export` ジョブだけが動く。
