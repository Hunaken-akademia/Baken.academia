# 参考表示のための公式馬場資料収集

クッション値・含水率の実測に加え、砂厚測定表、砂入れ替え・洗浄、路盤改修、散水、芝刈り、芝の状態、ばんえいの砂障害・ヒーティング等の公式資料を確保する。予測補正とは独立した収集で、数値の有意差がなくても出典付き参考資料として利用できるようにする。

## 収集対象

既存の中央2018～2026年の公式PDF収集、高知の2019年以降の公式砂厚記事収集に加え、`config/track-reference-sources.json` の公式資料71件を起点に関連資料・PDF・記事中の画像を辿る。

| 対象 | 主な資料 |
| --- | --- |
| 中央 | 現在掲載中の馬場情報、開催の馬場概要、クッション値・含水率の解説、ダート砂の仕様 |
| 笠松 | 開催前砂厚測定の記事、測定図のPDF・画像 |
| 園田・姫路 | 内ラチからの地点別砂厚、調整方針、砂入れ替え |
| 名古屋 | 砂情報、整備履歴、関連測定・整備告知と添付資料 |
| 金沢 | 内沿い・中央・外沿いの砂厚調整、作業図 |
| 盛岡・水沢 | 開催前の走路状況、芝の管理、砂厚・散水方針 |
| 門別 | 外走路の砂厚調整告知 |
| 大井・船橋・浦和・川崎 | 砂厚変更、砂の産地・種類、入れ替え・洗浄、路盤改修 |

| 佐賀 | 公式サイトを探索。具体的な測定系列は未確認であり、取得済みと扱わない |

## 保存と扱い

`collect_track_reference.py` は公式ホストの許可リスト内で取得し、最大240資料・リンク深さ2・同一ホストへの開始間隔3秒を上限とする。403/429/503や公式メンテナンスを確認したホストでは、それ以上の取得を止める。途中でもマニフェストを保存し、失敗を記録する。

原文バイト、原文SHA256、元URLと最終URL、親リンク、取得日時、形式、抽出テキスト、日付の言及、関連語を保存する。PDFの画像や複雑な測定図は未検証として保持し、読み順から測定地点や数値を推測しない。原HTMLは動的表示に必要な値を含まないこともあるため、ページ保存と数値取得は別に判定する。

記事の日付の言及は測定日・公表日・施行日へ自動変換しない。管理目標、整備後の仕様、実測、変更予定・延期は原文確認まで区別未確定とし、`measurement_validated=false` を付ける。古い告知を現在の値として扱わず、欠測日への補完も行わない。地方の砂厚を芝クッション値へ換算しない。

GitHub Actions `Collect official track references` で一度実行し、原資料と索引を90日保存する。自動定期実行・モデル公開・画面反映は追加していない。収集上限・エラー・未検証資料を含むため、全場・全期間の網羅完了とは扱わない。

検証：公式ホスト限定、UTF-8・Shift_JISの日本語、記事のPDF・画像リンク保存、ナビゲーションと無関係な添付の除外と、HTTP 200の404ページを成功扱いしないこと・403後のホスト停止を5件のテストで確認。

## 過去資料の追加収集

笠松の公式ニュースで公開されている年・月の選択機能を確認し、2018年1月～2026年10月の106か月を検索起点に追加する。過去月の一覧に測定記事が見つかった場合だけ記事と添付へ進み、存在しない記事IDを推測して走査しない。古い月に現在の記事が返る可能性もあるため、一覧指定年月を測定日や記事日として流用しない。

佐賀について、公式コース説明および2023年・2026年の本走路砂入替工事公表資料も追加で発見した。工事の入札・契約・工期は、施工完了や日別の馬場実測を意味しない。調教走路と本走路も混同しない。

追加カタログ `track-reference-history-sources.json` は111起点・最大400資料。`Collect historical track references` で別の単発収集を実施し、最初の収集と同じ実行枠で順番に動かす。原資料は90日保存する。

中央の現在値はページ本体とは別の `_data_cushion.html`、`_data_moist.html`、週間天候データも対象にした。文字コード宣言がないShift_JIS断片を実際に確認し、UTF-8固定で日付や場名を壊さないよう読取を修正した。これらは年月が省略されるため、年を推測して過去の日別測定値へ追加しない。
