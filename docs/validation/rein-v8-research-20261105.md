# REIN v8 研究：展開シナリオ混合と当日馬場傾向の判定（2026-11-05 準備）

研究専用です。本番のモデル・買い目・画面は変更しません。

## 目的

1. **展開シナリオの混合**: 「展開の発生確率 × 展開ごとの着順確率」で買い目の確率を作る。今の3連系は1つの着順確率から組み合わせを計算するため、「前が残る展開なら先行馬がまとめて来る」といった馬どうしの相関を表せない。
2. **当日馬場傾向の判定**: 同じ日・同じ競馬場・同じ馬場種別で、そのレースより前のレース番号だけを使って傾向を測る。3レース以上あり、偏りが標準誤差の2倍以上ある日だけ予想に効かせ、それ以外の日は0にする。

## 定義（`src/baken_academia/race_scenarios.py`）

- 展開ラベル（完了レースの事後ラベル。予想の入力には使わない）：1〜3着馬の第1コーナー位置（頭数比）の平均が、2019〜2021年の3分位で前寄りなら「前残り」、後ろ寄りなら「差し決着」、間なら「平均」。
- 当日傾向：先行レースの上記平均と基準平均の差。縮小版は (合計) / (レース数 + 3)。判定版は縮小版に判定（3レース以上かつ |z| ≥ 2、ばらつきの下限0.08）を掛けたもの。
- 展開確率モデル：多項ロジスティック回帰。入力は出走前に分かる隊列の形（逃げ候補数・脚質判明率・前走位置の平均）、頭数、距離、競馬場、馬場種別、馬場状態、クラス、当日傾向（方式による）。
- 展開別の着順確率：本番v4と同じ設定のLightGBMに実際の展開ラベルを加えて学習し、予想時は3つの展開それぞれを仮定して計算する。
- 買い目：現行の着順確率（人気70%＋v4 30%）に、展開ごとの倍率 p(着順|展開) / p(着順) を掛けて展開別にHarville計算し、展開確率で重み付けして合計する。倍率なしなら現行と完全に一致する（テストで確認）。

## 検証設計

- モデルはすべて2024年まで（本番と同じ期間）で学習。当日傾向の3方式（なし・常時・判定つき）から2025年の的中率合計で1つ選び、2026年で確認する。
- 現行との差に日単位ブートストラップ95%区間を付け、2025年と2026年の両方で下限が0を超えた券種だけを pass とする。
- 判定が有効になったレースの割合と、判定の向きが実際の展開と一致した割合も記録する。
- 結果の公開時刻は履歴に含まれないため、先行レースの結果が発走前に見られたという前提は事後研究上の仮定。2026年は過去研究でも見ているため、pass でも本番前に発走前保存予想で影運用する。

## 実行

`main` へのコミットメッセージに `[rein-v8-research]` を含め、`.github/rein-v8-research-request.json` を更新すると `rein-v8-research` ジョブだけが動く。結果は成果物 `rein-v8-research-<run id>`。
