# REIN v7 研究：市場合成とREIN指数（2026-11-05 準備）

研究専用です。本番のモデル・買い目・画面は変更しません。

## 目的

1. **市場合成**: 本番の「人気70%＋着順別REIN30%」という固定配分を、着順ごとの条件付きロジット（`src/baken_academia/market_stack.py`）に置き換えたときに的中率が上がるかを測る。入力は人気由来の市場確率、REINの着順別確率、他の着順の確率、頭数・芝ダート・クラス・人気の割れ具合との交互作用。2・3着の確率の尖り方もこの段階で学習するため、3連系の組み合わせ計算の補正を兼ねる。
2. **REIN指数**: 走破タイムをコース・距離の基準タイム、当日の馬場の速さ（同日・同場・同馬場種別の上位馬とクラス基準の差）、斤量で補正した独自のスピード指数（`src/baken_academia/rein_index.py`）。当日のレースが少ない日は、公式のクッション値・含水率から推定した馬場差へ寄せる。予想に使う特徴量は、その馬の過去の指数（前走、近3走平均、近5走最高、上昇度、同じ馬場種別の近3走、出走馬内の相対値）だけで、今回・同日・未来のレースは含めない。

## 検証設計

- 着順モデルは本番 rein-role-v4 と同じ設定で、拡大窓で再学習する（〜2021→2022、〜2022→2023、〜2023→2024、〜2024→2025・2026）。2022年以降の確率はすべて学習外。
- 指数の基準タイムとクッション値の補正式は2019〜2021年だけで作る。
- 市場合成は2022〜2024年で学習、特徴量の組と正則化は2025年で選び、2026年で確認する。
- 比較対象は「人気のみ」「現行（人気70%＋v4 30%）」「市場合成（v4）」「人気70%＋v7 30%」「市場合成（v7＝v4＋REIN指数）」の5方式。
- 指標は着順別の対数損失・Top1/3/5、8券種の現行点数上限でのレース的中率。現行との差に日単位ブートストラップ95%区間を付け、2025年と2026年の両方で下限が0を超えた券種だけを pass とする。
- 2026年は過去の研究でも見ているため、pass でも本番切り替えの前に発走前保存予想での影運用を行う。

## 実行

`main` へのコミットメッセージに `[rein-v7-research]` を含め、`.github/rein-v7-research-request.json` を更新すると `rein-role-model-to-supabase.yml` の `rein-v7-research` ジョブだけが動く（モデル公開ジョブはこのタグでは動かない）。結果は成果物 `rein-v7-research-<run id>` の `report.json` と `summary.md`。
