# REIN 騎手の条件別実績（2026-10-05）

要望：競馬場・芝ダート・距離・右左回り・枠で騎手の実績を見たい。出走馬の比較と並べ替えも追加。

中央25,713レース・346,656騎乗・175人（2019-01-05〜2026-09-13）、地方103,129レース・1,043,193騎乗・522人（2019-01-01〜2026-09-27）を使用。障害・ばんえいは対象外。これは条件別参考集計の期間で、日次更新した本番モデル履歴の最終日とは別。画面に期間を明記する。

各条件で出走数・1/2/3着の実数・勝率・連対率・3着内率を集計。枠は1〜2/3〜6/7〜8枠、距離は同じメートル数。右左回りは取得済みコース説明だけを使用し、競馬場名から推測しない。中止・失格は出走数に含め、取消・除外を除く。平滑化した旧モデル値からの逆算は行わない。

騎手IDを優先。同名しかない場合は空白を除いた一致が一意の時だけ使い、曖昧な名前では保留する。少数を隠す最低母数フィルター（0/30/50/100走）、3着内率のWilson95%区間、通算との差を表示。APIは中央/地方別の会員認証済みパスに分け、最大18頭だけを返す。

## 期間を分けた確認

2019〜2024年に50騎乗以上で騎手自身の通算3着内率を3ポイント以上上回った条件を選び、2025年・2026年を集計。2026年は既に別研究でも参照した回顧期間。

| 条件 | 中央2025 / 2026の3着内率 | 地方2025 / 2026の3着内率 |
|---|---|---|
| 場×芝ダート | 28.75% / 29.68% | 38.81% / 39.03% |
| 場×芝ダート×距離 | 28.17% / 28.64% | 36.59% / 37.27% |
| 回り | 37.65% / 33.86% | 34.59% / 36.25% |
| 枠 | 25.94% / 21.21% | 29.95% / 29.66% |

比較母数・同じ騎手の学習期間基準は各leagueのJSONに保存。中央の枠では2026年に騎手通算基準21.44%を下回った。場・距離・回りで傾向が残るものはあるが、騎乗馬の能力や人気の構成を統制した因果比較ではない。これは新ファクターを本番の予想に加えた時の的中率比較ではないため、追加の予想加点は行わず、参考データとして公開する。

過去レース閲覧時も、この参考データは表記した全期間の集計。保存予想の当時の値や当時の入力には使用しない。回収率・騎手の写真・種牡馬別成績は本変更の対象外。
