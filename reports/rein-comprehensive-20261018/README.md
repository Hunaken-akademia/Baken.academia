## 期間の分離と判定

新モデルの学習は2019〜2024年。2025年1〜6月で方式を選び、同年7〜12月で確認、2026年で再確認しました。基準モデルは中央の既存モデル（阪神・良の3着補助を含む）、地方の既存方式を2024年末までで再学習したものです。

同じ日の結果がその日の特徴量に入らないよう、日単位で集計してから過去分だけを参照します。着順評価には当日の人気・オッズを入力していません。人気は穴馬群の評価に使います。

主要な着順比較の95%区間は開催日単位の再標本化で算出。条件探索の区間・検定には日単位の集計から求めた標準誤差を使い、利益基準を通過する候補には再標本化も要求します。条件を大量に調べた影響は、重複条件にも対応するBenjamini–Yekutieli法で補正しました。最終まとめでは、着順評価について中央・地方・全着順・追加特徴群をまとめて再補正しています。個別JSONの旧ローカル判定より、summary.jsonとcondition-global-audit.jsonの判定を優先してください。

**2026年は以前から何度も見た期間です。今回の成績は「完全な未検証データで証明した成績」ではありません。過去の基準方式や候補定義には後年の知見もあり、当時保存した予想の再生でもありません。**

## 検証上の制約と次の判断

- 確定オッズ・最終人気を使った購入実験は、締切前に実際に発注できた成績ではありません。変動、取得遅延、欠損、発注時点の制約は未再現です。
- 地方のばんえい、取消・除外・中止・失格・欠落のある出走表、着順評価では6頭未満を除外。対象外への一般化は未確認です。同着は、該当着順の正解が一意でない評価から除外しました。
- グレード判定は取得済みのレース名・クラス表記で識別できたものに限定。完全な重賞台帳との照合や、各G1を個別に十分な件数で評価したものではありません。
- 中央の新しい着順候補から任意の買い目を生成した回収率は未検証。中央の回収検証は、払戻照合済みの既存オッズ購入方式に限ります。
- 今回は取得済みデータで定義した探索範囲を検査しました。無限にある条件の全組み合わせを尽くしたという意味ではありません。
